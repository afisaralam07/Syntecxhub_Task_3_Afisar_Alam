# Titanic Dataset EDA – Task 3

## Objective
Perform exploratory data analysis on Titanic dataset to understand survival patterns.

## Analysis Performed
- Missing value inspection
- Correlation heatmap
- Survival analysis by gender, class and embarkation port
- Age distribution and violin plots
- Feature engineering (Family Size)
- Fare distribution analysis

## Key Insights
- Female passengers had significantly higher survival rates.
- First-class passengers showed better survival probability.
- Higher fare passengers had better survival outcomes.
- Small family groups had improved survival chances.
- Cabin column contains high missing values.

## Tools Used
Python, Pandas, Matplotlib, Seaborn
